ORCA

Marine EcOsystem Reasoning with Collaborative Agents

An Agentic AI platform that lets fishermen, coast guard officers, disaster management officials, and the general public ask natural-language questions about marine safety and get answers grounded in real live weather/ocean data, a deterministic risk engine, and a retrieval-grounded knowledge base of real government and institutional documents — never invented numbers, never fabricated citations.

This is a transparency page. Every field ORCA shows is either genuinely LIVE (fetched from a real API at query time), LIVE-DERIVED (computed from a real live field), or MOCK (a fixed demo value, used only because no free live source exists for it) — never presented as more real than it actually is.
